---
name: social-ux-triggers
description: Use this skill when developing features related to viral growth, sharing, notifications, user profiles, dashboard summaries, or peer-to-peer loops.
---

GrowthPilotAI aims to natively connect users through growth-driven psychological triggers. When building user flows, maximize behavioral loops:

1. **Gamified Milestones & Sharing**: When a user achieves a saving or investment goal, generate interactive, visual summary cards optimized for easy native sharing (Social Proof).
2. **Peer-to-Peer Fin-Loops**: Design split-billing, shared wallets, or collective goal-tracking features with highly intuitive micro-interactions that nudge users to invite their network.
3. **Reciprocity Triggers**: Implement social reward triggers (e.g., unlocking custom app themes or premium financial insights when a user assists a peer or sends a referral).
4. **Frictionless Onboarding**: Optimize multi-user touchpoints so that receiving a shared link allows peer interaction with minimal structural barrier.
