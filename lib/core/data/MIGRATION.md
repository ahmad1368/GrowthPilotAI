# 🛡 استراتژی مهاجرت دیتابیس (Migration Strategy) - GrowthPilotAI

این پروژه از **ObjectBox** استفاده می‌کند. برای جلوگیری از پریدن داده‌های مالی کاربران، رعایت نکات زیر الزامی است:

### ✅ تغییرات مجاز (خودکار)
- افزودن یک Entity جدید.
- افزودن یک فیلد جدید (Nullable یا با مقدار پیش‌فرض).

### ⚠️ تغییرات حساس (نیاز به UID)
هرگاه فیلدی را **تغییر نام** می‌دهید، نباید فقط نام آن را عوض کنید.
1. به فایل `objectbox-model.json` بروید و UID فیلد قدیمی را پیدا کنید.
2. از آنوتیشن `@Property(uid: ...)` بالای فیلد جدید استفاده کنید.

### 🚀 گردش کار انتشار (Release Workflow)
- همیشه قبل از کامیت، دستور `flutter pub run build_runner build` را اجرا کنید.
- فایل `objectbox-model.json` باید حتماً در Git وجود داشته باشد.
